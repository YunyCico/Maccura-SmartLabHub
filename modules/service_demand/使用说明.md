# 数据中台 · 对外数据拉取控制台

把数据中台的**对外数据拉取接口**参数可视化到页面上，你在页面填参数 → 自动按接口文档的步骤调接口、拿文件、解析数据、展示结果。

严格实现自《对外数据拉取接口（文件下载版）》。

---

## 一、怎么启动

双击 `启动控制台.bat`，浏览器自动打开 `http://127.0.0.1:8100`。

首次运行会自动创建 Python 环境并装依赖（约 1-2 分钟），之后就秒开。
关闭黑色命令行窗口 = 停止服务。

---

## 二、页面需要你填的只有两项

按接口文档「AI 代码生成集成说明」的要求，中台地址与登录账号属于**固定配置，已内置在代码里**，用户无感：

| 项 | 值 | 来源 |
|---|---|---|
| 中台接口地址 | `http://10.19.51.251:8080` | 文档固定 |
| 登录账号 | `api_data` | 文档固定 |
| 登录密码 | `M_bWFjY3VyYTEyMw==` | 文档固定（已编码，直接传） |

**页面上只有两个输入框**，这两个要向数据中台管理员申请：

1. **数据权限用户名 `username`** — 必须与 Key 所属用户一致
2. **对外接口 Key `X-Open-Api-Key`** — 管理员分发，保存后本机存储，页面只显示掩码

登录、Token 获取、`Authorization` 注入全部由代码自动完成，Token 会缓存复用、过期自动重登。

## 三、页面结构

| 区域 | 作用 |
|---|---|
| 顶部状态条 | 连接状态、登录账号、Key 掩码、Token 是否复用缓存 |
| 左侧「必要配置」 | 上面那两项 |
| 左侧「拉取参数」 | 接口文档全部参数，做成可点选的选择器 + condition 可视化编辑器 |
| 右侧结果区 | 下载链接、执行回执（含分页统计）、数据表预览、字段画像、指标/组合结果、历史记录 |

## 四、接口对照

| 页面入口 | 接口 |
|---|---|
| 拉取参数 → 拉取数据 | `POST /api/auth/login` → `POST /api/open/data/pullFile` → 按 `downloadUrl` 下载 |
| 供应商指标 → 批次合格率 | `POST /api/open/data/supplier-pass-rate` |
| 供应商指标 → 按时交付占比 | `POST /api/open/data/supplier-delivery-rate` |

### 调用流程（文档第 2 节）

```text
1. api_data 登录，取 data.token
2. 请求头带 Authorization: Bearer <token>
3. 请求头带 X-Open-Api-Key: <key>
4. 请求体 username 填 Key 对应的授权用户名
5. 调 POST /api/open/data/pullFile，拿 downloadUrl
6. 立即下载 ZIP（文件 3 分钟后会被服务端清理）
7. 解析 ZIP 并展示
```

## 五、参数说明（对齐文档第 5 节）

| 参数 | 类型 | 页面形态 |
|---|---|---|
| `username` | String | 输入框 |
| `busDomain` | String[] | 业务域标签多选 |
| `tableName` | String[] | 表名标签多选 + 搜索 + 手填 |
| `metricsDomain` | String[] | 指标域标签多选 |
| `metricsName` | String[] | 指标标签多选 + 手填 |
| `combinationDomain` | String[] | 手填（平台未提供候选） |
| `combinationName` | String[] | 手填 |
| `condition` | Object | **可视化编辑器**：按表配多个条件，AND 相连 |
| `pageNo` / `pageSize` | Integer | 两个数字框，必须同时填 |

### condition 操作符（文档 6.3）

| operator | 含义 | value |
|---|---|---|
| `eq` | 等于 | 单值 |
| `like` | 包含/模糊 | 单值 |
| `gte` | 大于等于 | 单值 |
| `lte` | 小于等于 | 单值 |
| `in` | 在范围内 | 数组或逗号分隔 |
| `isNull` | 为空 | 无需填（页面自动禁用） |
| `isNotNull` | 不为空 | 无需填（页面自动禁用） |

页面已做**实时校验**：字段名非法（非字母/数字/下划线开头）会红框+红字提示，
`isNull`/`isNotNull` 自动禁用值输入框，`condition` 的表名必须与已选表一致。

### 分页规则（文档 5.3）

- 都不传 → 全量拉取
- 都传 → 对每张表分别分页（不是合并后分页）
- 只传一个 → 400，页面已提前拦截
- `pageSize` 范围 1~10000

## 六、返回的 ZIP 结构（文档 8.2）

```text
├── tables/
│   ├── <表名>.columns.json    字段元数据（fieldName / comment / fieldType / length）
│   └── <表名>.csv             数据，第一行为字段名
├── metrics/
│   └── <指标码>.json
├── combinations/
│   └── <组合码>.json
└── manifest.json               清单
```

页面会把 `columns.json` 里的**中文字段注释和 SQL 类型**挂到表格列头和字段画像上，
分页请求时还会显示「本次 N 条 / 可见总量 M / 第 X 页（共 Y 页）」。

## 七、如果拉下来是空的

页面出现黄色提示「接口调用成功，但所有资源均返回 0 条」。

**这不是工具的问题**，是 `X-Open-Api-Key` 所属用户的**数据权限范围**没覆盖你选的表/指标。
表现是：平台网页里直接查这些表能看到数据，但通过对外接口拉是 0，
`manifest.json` 的 message 里会列出「无权限或读取失败」的清单。

解决：找数据中台管理员，在「系统运维 → 开放接口 Key」或数据地图数据权限里，
给对应 username 勾上业务域/表授权。

在那之前可点「预览解析效果（本地样本）」看完整效果（样本严格按文档目录结构生成）。

## 九、开发

```bash
# 后端
.venv/Scripts/python.exe -m uvicorn service_portal.main:app --host 127.0.0.1 --port 8100 --app-dir backend

# 前端（开发模式，自动代理）
cd frontend && npm run dev    # 端口 5180

# 构建
cd frontend && npm run build

# 测试（离线）
.venv/Scripts/python.exe -m pytest tests -q
```

## 十、改配置

页面左上角「修改」直接改，不用动文件。
也支持环境变量：`DFP_OPEN_API_KEY`、`DFP_USERNAME`。
