本程序及本说明仅限「迈克生物集团 · 实验室运营管理部」内部使用。

部门：实验室运营管理部　|　程序名称：智慧实验室运营管理-数据汇总助手

当前版本：v2.4.0　|　界面配色与品牌标识：迈克生物

本版新增：分析报告支持多天数据 —— 以前报告默认「数据就是一天」，如果你给的是好几天的数据，程序会把不同天的同一小时错误地加在一起（比如 09/19 和 09/20 的 9 点都算成「9:00–10:00」一个格子），算出来的峰值、集中度、实际速度全都是错的。现在程序会自动识别数据横跨几天，并把时段按天隔离：每天的同一小时是两个独立格子、不会相加；模板②的队列重建和饱和窗也改成每天各算一遍（队列是「当天从零起算」的积压量，跨天累加会把前一天的积压带进第二天，速度就算错了）。报告里会多一节「逐日对比」，把每天的完成量、峰值时段、实际速度并排列出来，并取速度最高的那天作为能力证据。单天数据的行为和以前完全一样。

上一版：「保存并替换原文件」 —— 在「原始数据预览」里改完数据后，现在可以直接写回这份数据表本身（不用每次重新编辑一遍）。覆盖前会自动备份原文件到「导出结果\_原始文件备份\」；写回后工作表列表、列名、行数会自动重新识别；删掉的列不写回，删掉的子表从文件里真正消失。这一步必须你主动点才会执行 —— 编辑本身默认仍然只改内存。

上一版：在预览里直接改数据 —— 能改单元格、删整行、删整列、删掉整个子表，带撤销/重做和改动标黄；改完可以「保存并替换原文件」写回，或「导出为新文件」另存一份到「导出结果」目录。

再上一版：一键出分析报告 —— 汇总完不用自己想做图，选个模板就出一份独立 HTML 报告。先做两个模板：📊 设备模块负载与堵塞点（全天活儿什么时候涌来、哪个模块被压满、堵点在哪）和 🧭 免疫线实际测试速度·证据链（队列重建锁定饱和窗、算出模块真实速度、含均衡化模拟）。报告存进程序目录的「分析报告」文件夹，同名不覆盖，可直接打印成 PDF 或转发。

上一版：结果卡片下方「结果分析」，分「数据概览」（每列有没有缺失、是数字还是文本、都分布成什么样、极值是多少）和「数据透视」（行维度 × 列维度 × 六种聚合，做交叉表，可直接导出 Excel/CSV）。

更早：概览「表头结构分组」的每组多了「预览」按钮 ——

合并前先看一眼会合并成什么（多少行、哪些列、每张表各贡献多少行、数据长什么样）。

设置页「最近导出的文件」可删除（单条删 / 清空全部）；

数据源管理可直接查看原始数据表（按 Excel 原样显示、可切工作表、可翻页）；

「汇总提取 → ① 选择要汇总的数据表」加了「↻ 刷新」按钮，刚导入的表格

这里没出现时点一下即可；切到本页也会自动同步最新数据。

一、怎么启动

双击文件夹里的 start.bat。

  • 会弹出一个黑色命令行窗口（不要关它，关了程序就停了）
  • 大概 1 秒后浏览器自动打开操作界面
  • 如果浏览器没自动开，手动访问窗口里显示的地址，例如 http://127.0.0.1:8765/
  • 界面「设置」页能看到当前程序版本，方便确认装的是不是最新版

程序不联网也能用（除「AI 助手」和「钉钉在线文档」以外的功能都不联网）。

关掉那个黑色窗口 = 退出程序。

三、导入数据

方式 1：拖进来

把 Excel / CSV 直接拖到「数据源管理」页面的虚线框里。可以一次拖多个、也可以拖整个文件夹里的文件（多选）。

方式 2：扫描文件夹

把文件夹路径粘贴到输入框，点「扫描文件夹」。程序会递归找里面所有 .xlsx / .xlsm / .csv。 例如：

C:\Users\98319\DingDrive (孟鹏杰)\迈克生物集团\我的文件\实验室运营管理部\智慧实验室项目统计

方式 3：钉钉在线文档

见下面「三点五、钉钉在线文档」。

导入时程序会自动做的事：

  • 识别每张工作表
  • 自动猜表头在第几行
  • 多行表头 / 合并单元格会自动拼成一个字段名（如第 1 行「2024年」跨两列、第 2 行是「1月」「2月」，会拼成 2024年-1月、2024年-2月）
  • 从文件名自动猜「实验室」和「表类型」

导入的文件会复制一份到 library\sources\，所以你原来放在钉钉网盘、桌面上的文件可以随便挪，不影响程序。

表头猜错了怎么办？

点该行的「详情」，把「表头行」改成正确的行号：

  • 单行表头填 1
  • 两行表头填 1-2
  • 表头在第 3 行填 3

点「重新识别」立即生效。

「读取方式」：列式表格 / 信息表

有些工作表不是"一行一条记录"的列表，而是左边一栏写标签、右边一栏写内容，例如：

AB
填报日期2026-09-15
实验室名称绵阳市人民医院-检验科
联系人张三

这种表用普通列式读法会读出一堆错位数据。程序在导入时会自动识别这类结构并标上橙色的「信息表」标签， 把它读成「项目 / 内容」两列。如果自动判断错了，在「详情」里的「读取方式」下拉框手动切换即可。

三点二、查看原始数据

「数据源管理 → 已导入数据表」每一行有 预览 / 详情 / 删除 三个按钮。 「预览」 用来按 Excel 的原样查看文件内容 —— 拿不准"这份表到底长什么样""第几行有问题"时用它。

预览（本功能）详情里的「数据预览」
看的是什么原始底稿：从磁盘文件原样读回识别结果：程序清洗后的数据
第 1 行就是文件的第 1 行（空行、标题行都在）已经跳到表头行，标题行被去掉
多层表头保持原样，占几行就是几行已拼成一个字段名
合并单元格保留原样已按合并且填充
能切工作表吗✅ 点上方标签可切该文件的任意工作表❌ 只看第一个工作表
适合用来核对原始内容、定位"第几行数据不对"确认"字段识别对不对"

打开后的界面：

  • 上方标签条 —— 该文件里的所有工作表，点一下切换
  • 左侧灰色列 —— 行号，就是 Excel 里的真实行号（1、2、3…），方便你和 Excel 对照
  • 表头 —— 写的是 列号 A / B / C…，对应 Excel 的列标
  • 右上角橙色角标 —— 「原样显示 · 未清洗」，提醒你这里没有做任何处理
  • 底部翻页条 —— 每页 50 / 100 / 200 / 500 行可选，默认 100 行，可用「首页 / 上一页 / 下一页 / 末页」翻

关于"列被裁掉"的提示：有些表在 Excel 里给整行拖过格式，程序读到的列数会被撑到 16384（Excel 的列上限），

但实际有内容的可能只有十几列。这种情况下预览会自动裁掉末尾的空列，并在信息行提示

「已裁掉末尾空列（原 N 列 → 显示 M 列）」。这只是不显示空列，不会影响你的原始文件和汇总结果。

在预览里直接改数据

预览界面右上角有个 「编辑模式」开关（默认是关的，防止手滑改坏数据）。把它打开后，就能直接在这张表上动手：

想干什么怎么做
改一个格双击那个格子 → 直接输入新内容 → 按 Enter 确认（按 Esc 取消）
清空一个格先点一下选中它（会有一圈蓝色框）→ 按 Delete 或 Backspace
删整行把鼠标移到那一行的行号上，会出现一个红色 ✕，点它就删这行
删整列把鼠标移到列号（A / B / C…）上，会出现红色 ✕，点它就删这列
撤销 / 重做上方工具条的「↶ 撤销」「↷ 重做」，或键盘 Ctrl+Z / Ctrl+Y
删掉整个子表把鼠标移到上方的子表标签上，会出现红色 ✕，点它就删掉整个子表（见下）
不要这些改动了点「丢弃编辑」，一键恢复成原始数据
把改完的结果保存回这份表点「保存并替换原文件」，直接覆盖这份数据表本身（覆盖前会自动备份原文件，见下）
把改完的结果另存一份点「导出为新文件」，选 xlsx 或 csv，另存一份、不动原表

改过的格子会标黄，右上角有个橙色小三角；上方会显示「● 已改 N 处」。

保存并替换原文件

改完之后，如果你希望这份数据表本身就是改完的样子（而不是每次都要重新编辑一遍），点工具条上的「保存并替换原文件」：

要点说明
会覆盖什么直接写回你导入的那份文件（library\sources\ 里的那份）。写完后预览、汇总、分析报告全都用新数据
覆盖前自动备份第一次写回前会先把原文件复制一份到「导出结果\_原始文件备份\」，文件名带时间戳（如 0919-1_20260921_174500.xlsx）。备份成功才会动手，备份失败会中止
中途断电会不会毁文件不会。程序先把结果写到一个临时文件，写完确认无误后再一次性替换原文件，不会出现"写到一半原始文件坏了"
删掉的列 / 子表怎么算你留住什么就写回什么 —— 删掉的列不写回，删掉的子表从文件里消失（会自动重算工作表列表）
写回后索引会自动刷新工作表列表、列名、行数会重新识别一次，不用你手动重新导入
要确认一次弹框会写明：要覆盖哪个文件、会写几个子表多少行、哪些子表会被删掉、备份落在哪
误覆盖了怎么恢复去「导出结果\_原始文件备份\」找带时间戳的那份，复制回来覆盖即可

保存成功后信息行会显示一个绿色角标「已保存回原文件」；如果之后又改了东西，角标会自动消失（提示你还有未落盘的改动）。

写回后本次的编辑状态会清零（改动已经落到文件里了，不需要再叠一层），撤销栈也一并清空。

删掉整个子表

有些文件里带着整张用不上的工作表（比如样表、说明页、去年的旧数据）。不用先去 Excel 里删掉再重新导入 —— 在预览里把鼠标移到上方的子表标签上，标签右边会出现一个小红 ✕，点它即可删掉整个子表。

要点说明
红 ✕ 什么时候出现只在编辑模式开着、鼠标移到标签上时出现。平时看不见，避免手滑
删的时候会先确认弹框会明确告诉你：这个改动不写成文件、只影响界面数据、可随时撤销
删了当前正在看的表会自动切到右边相邻的子表；右边没有就切左边，保证界面不空
撤销 / 重做和改单元格共用同一条撤销时间线，Ctrl+Z 就能把它变回来
删错了想全恢复点「丢弃编辑」，所有被删的子表会全部回来
至少留一张不允许把子表全删光（全删了预览就没东西可看了），删到只剩一张时 ✕ 不再出现
导出时怎么算选 xlsx 会把你剩下的所有子表各写成一个工作表、装进同一个新工作簿；被删掉的不导出。选 csv 一次只能存一张表，所以只导当前这张，界面会提示
保存回原文件时怎么算被删掉的子表从文件里真正消失；留在界面上的子表照原样写回

被删的子表名会在上方显示成「已删 N 个子表」的角标，一眼能看到这次动了哪几张。

删子表这个动作本身不写成文件，要落盘同样点「保存并替换原文件」或「导出为新文件」。

⚠️ 默认只改内存，想落盘要你明确点一下

预览里的编辑默认不落盘 —— 你导入的那份文件是「数据源」，汇总、分析报告、数据透视全都依赖它。

故意这么设计：如果在预览里改一下就悄悄改掉原始文件，你后面所有的汇总结果都会跟着变，而且你根本不会发现。

所以规则是：

  • 你在预览里怎么改，磁盘上的原始文件一动不动（改完去文件管理器看，修改时间、大小都没变）
  • 想落盘有两条路，都必须你主动点：
    ① 「保存并替换原文件」→ 覆盖这份数据表本身（覆盖前自动备份到「导出结果\_原始文件备份」）
    ② 「导出为新文件」→ 另存到「导出结果」文件夹，文件名带「已编辑」字样，不覆盖原表
  • 什么都不点就关掉程序，这些改动就没了（重新打开又是原始数据）—— 这是预期行为，不是 bug

底部提示条会一直提醒你当前状态：没改动时是灰色的说明文字；一旦有未保存的改动，会变成橙色的警示条。

三点三、删除不需要的导出文件

每次在「汇总提取」里点「导出 Excel」，程序都会在程序目录的「导出结果」文件夹里留一份备份， 方便你过一会儿再下载一次。用得久了这个文件夹会越攒越多，现在可以直接在程序里清理。

位置：设置 → 最近导出的文件。

操作怎么用会删掉什么
删除（每条右侧）点某一条右侧的「删除」这条记录 + 「导出结果」里对应的那个文件
清空全部（标题右侧）点卡片标题右侧的「清空全部」「导出结果」里的全部导出文件

两个操作都会先弹确认框，确认后才动手；删掉的文件不能恢复。

几点说明

  • 只会删程序自己留的备份。你之前点「导出 Excel」时浏览器另存到「下载」文件夹的那一份，

以及你自己拷到别处的副本，都不受影响。

  • 「清空全部」只删文件，不会删子文件夹 —— 万一你往「导出结果」里放了别的东西，不会被动到。
  • 列表默认只显示最近 15 份。如果文件比这多，列表下方会提示「共 N 份，这里只列出最近 15 份」，

较早的可以点「打开导出目录」去文件夹里看。

  • 想连文件夹一起清理，也可以用卡片上方的「打开导出目录」，在资源管理器里自己删。

和「清除结果」的区别

「汇总提取」里的「清除结果」清的是界面上当前这份汇总结果（数据表、勾选、已导出的文件都不动）； 这里的「删除」清的是磁盘上已导出的文件。两者互不影响。

三点五、钉钉在线文档

在「数据源管理」页有一块「钉钉在线文档」。它提供三条路，按你的条件选一条即可：

方式需要什么怎么用
① 扫描钉钉目录（最稳，推荐）什么都不用配点「扫描钉钉目录里的表格」，程序自动在钉盘（DingDrive）挂载目录、钉钉下载目录、桌面、文档里找 .xlsx/.csv，勾选后点「导入所选」
② 直连钉钉（本地 MCP）装「钉钉」连接器 + 填访问令牌点「测试连接并列出工具」，成功后就能直接调钉钉的工具把在线表格取回来
③ 命令行模板装了钉钉 CLI在 ③ 填一条命令模板（{url}、{out} 是占位符），点「用命令行拉取并导入」

关于①②③怎么选：

  • 钉钉的在线文档本质是网页，要汇总必须先变成表格数据。所以最省事的是：在钉钉里「导出为 Excel」，然后走①扫描，或直接拖进虚线框。
  • 方式②需要钉钉连接器提供访问令牌。程序会自动检测钉钉桌面客户端有没有在跑（读本机端口），

检测到了会显示绿点；令牌只保存在本机 library/index.json，界面只回显掩码，不回传明文。

  • 三条路都不影响其他功能，不配也完全能用。

提醒：如果钉盘没挂载到本机（比如钉钉重装过），①扫不到文件是正常的 ——

那就手动「导出为 Excel」再拖进来，或者把钉盘重新挂载一下。

三点六、字段字典（纵向 / 横向）

「字段字典」页里列的都是表头本身——程序为了提示而拼上去的「（说明）」不算字段名， 会放到「同义写法 / 完整列名」那一栏里，不参与归类。

页面上方可以切换两种看法：

视图长什么样用来干什么
纵向列表一行一个字段，显示出现几个文件、几个工作表、涉及哪些数据表找字段、看同义写法
横向矩阵行 = 字段，列 = 数据文件，交点打 ✓（括号里是几个工作表用到）一眼看出哪些文件有同一个字段

底部两个按钮直接接下一步：

  • 「用这些字段纵向汇总」：勾选字段 → 跳到「汇总提取」，自动按这些字段把各文件纵向堆起来。

> 判断依据：横向矩阵里同一行 ✓ 越多，说明这个字段越通用，越适合纵向合并。

  • 「用这个字段做横向关联」：勾选一个字段（当"键"）→ 跳到「横向关联」，主表关联键自动填好。

> 判断依据：能当"键"的字段（比如"实验室名称""客户""序号"）适合横向关联。

四、汇总数据（最常用）

进「汇总提取」页，按 ① → ④ 四步走：

① 选数据表

左边列表里勾选要汇总的表：

操作说明
勾文件名前的方框该文件的所有工作表一起选 / 取消
勾具体某个工作表只选这一张
点文件名左边的 ▾ 箭头折叠 / 展开这个文件的工作表（文件多的时候很好用）
全部折叠 / 全部展开一键把所有文件收起来或铺开
全选 / 全不选一键全勾或全清
上面的搜索框按「实验室 / 表类型 / 文件名」筛选
仅选中表头一致的表打开一个弹窗，自己挑一张表当基准，再一键对齐（详见下）
查看已勾选打开一个弹窗，把所有已勾选的工作表汇总到一处，直接在里面取消勾选（详见下）
（概览页）一键合并在「概览」页的表头结构分组里，一键把同组表全部勾选 + 自动填好输出字段，直接跳到本页。详见「一键合并」一节

「全选 / 全不选 / 全部折叠」只作用于当前筛选后看得见的文件，

不会误改被搜索过滤掉、你看不到的表。

「仅选中表头一致的表」怎么用？

点按钮后会弹出一个基准表选择窗口，分三步：

第 1 步 · 选基准 在列表里点任意一行，它就成为基准（弹窗顶部会显示基准表）。也可以勾方框选多张表头相同的表组成基准组。

弹窗一开始会自动预选"列名最全的那张表"作为起点，一般直接用它就行。

第 2 步 · 选作用范围

范围用途
全库（默认）扫全库，把所有符合基准的表都挑出来 —— 适合"我要找齐所有同类表"
仅在已勾选的表里只在你已经勾好的表里做收缩，不新增表 —— 适合"已勾了一堆，帮我清掉不匹配的"

第 3 步 · 看预览，确认

弹窗会把你范围内的每张表分三档列出来，确认无误再点「按这个基准对齐勾选」：

档位标记处理
完全一致<kbd>表头一致</kbd> 绿勾上
缺列子集<kbd>缺 N 列</kbd> 橙勾上（缺的列汇总时留空）
表头不符<kbd>表头不符</kbd> 灰取消勾选

判定规则：

规则说明
只看表头不比对任何单元格内容，数据不同不影响判定
列名比对归一化后比较：全角转半角、去空格、去标点、转小写（「项目名称」=「项目 名称」）
忽略顺序列的顺序不同也算一致（A,B,C 与 C,A,B 视为同一结构）
允许子集这张表的列名只要能被基准组全覆盖就算一致，缺的列汇总时留空

举个例子（这也是为什么会需要"允许子集"）：

基准组 8 列：EQA计划大类 / 专业代码 / EQA名称 / 项目名称 / 项目缩写 / 是否参加 / 试剂品牌 / 是否重点关注

另一张表 7 列，只少「是否重点关注」→ 算一致，会被选中（那列留空）。

反过来，基准组 7 列、另一张多出「是否重点关注」→ 不算（多出的列基准组里没有）。

  • 点完的提示形如：已按 8 列的基准对齐：新增 15 张，取消 0 张不符，含 10 张缺列子集。
  • 点完后每张表后面会带标记（<kbd>表头一致</kbd> / <kbd>缺 N 列</kbd> / <kbd>超出基准</kbd>），一眼看出为什么被取消。
  • 基准组和范围会被记住，下次打开弹窗还是上次的选择。
  • 按 Esc 或点右上角 ✕ 可关闭弹窗，不做任何改动。

💡 为什么基准要自己挑，不能自动？

同一套模板会派生出一堆"兄弟表"（比如「室间质评填报」8 列、「正确度验证填报」7 列、

「参考实验室填报」7 列），它们互为超集关系。如果让程序自动投票，结果会随你

勾选的先后顺序漂移，很难预期；交给你指定，结果就完全可控。

「查看已勾选」怎么用？

勾了一堆表之后，如果想知道到底勾了哪些，或者想取消其中几张，不必回到左边长列表里一个个找 —— 点这个按钮。

弹窗会列出当前所有已勾选的工作表：

内容说明
顶部小计已勾选 12 张（+ 本次已取消几张）· 勾选的分布在 3 个文件里，一眼看出规模和分散情况
分组列表按文件分组，每组标出 已勾选 3/4 张（分子是还勾着的，分母是本窗口列出的）
每行内容工作表名 · 行数 · 字段数，下面一行是该表的字段清单
筛选框勾选很多时，按工作表名 / 文件名 / 实验室筛出想看的那几张
全部恢复勾选把筛出来的（或全部）重新勾上；如果你一张都没取消，它会提示「这些都已经勾选了」

取消勾选：点行、或点行首的方框都可以。

取消后这一行不会消失 —— 它就留在原位，只是勾选框变成空的、整行变淡，并在表名后标一个 <kbd>已取消</kbd>：

  • 方便对照着勾回来：想在几行之间来回比较、或者取消错了想撤回，直接再点一下那一行就勾回来了，不用重新找。
  • 方便看清改了哪几张：顶部会显示 本次已取消 N 张，被取消的行一眼可辨。
  • 分组小计同步：如 已勾选 3/4 张，立刻知道是这个文件里少了一张。

取消的效果立即生效并同步到主界面 —— 左边 ① 的勾选状态马上跟着变，不用再确认一次。

重新打开这个弹窗时，清单会按当时的勾选情况重新生成 —— 上次取消掉的那些不再出现，

也就是这里始终以"你当前真正勾了哪些"为起点，不会留一堆历史痕迹。

如果之前用「仅选中表头一致的表」设过基准，这里每张表还会标出

<kbd>表头一致</kbd> / <kbd>缺 N 列</kbd> / <kbd>超出基准</kbd>，

顺便就能看出这批表结构是否整齐。没设过基准就不显示这些标记（弹窗里有一句提示会说明原因）。

关闭方式：右上角 ✕、底部的完成，或按 Esc。关掉窗口不影响已做的改动（取消的勾选依然是取消的）。

② 选字段

右边会自动列出选中表里出现过的所有字段（按归一化去重，「服务需求」和「服务需求 」会合并成一个）。 勾上你要的字段就行。字段后面会写「出现在 5/8 张选中的表」。

③ 筛选条件（可选）

想只看某类数据时用。比较方式一律用符号显示（鼠标悬停会显示中文说明）：

符号意思符号意思
⊃包含⊅不包含
=等于≠不等于
>大于<小于
≥大于等于≤小于等于
∅为空≠∅不为空

例：「处理状态」⊃ 未处理；「日期」≥ 2026-01-01。 选 ∅ / ≠∅ 时后面的值框会自动灰掉（这两项不需要填值）。

④ 输出选项

  • 增加来源列：结果里多出「来源实验室 / 来源文件 / 来源工作表」三列，方便追溯（建议保持勾选）
  • 整行去重
  • 排序字段 / 条数上限

一键合并（从概览直接开工）

如果几张表的表头完全一致，不必在本页一张张勾 —— 直接在「概览」页操作更快。

怎么用

  1. 点左侧导航进「概览」
  2. 找到「表头结构分组」卡片 —— 程序会自动把表头（列名）完全一致的工作表归成一组
  3. 每组右侧有一个「一键合并」按钮，点它

点完之后程序做了什么

动作说明
勾选这组表把该组所有工作表追加进「① 选数据表」的勾选（不影响你已有的其他勾选）
自动填输出字段把「② 选要输出的字段」直接填成这组表的列名
跳到汇总提取自动切到「汇总提取」页，你只需再点「生成汇总表」

为什么能自动填字段？因为这一组的列名本来就完全一样，字段映射必然是 1:1，

不需要人工对齐。这也是「表头完全一致」这个分组存在的意义。

按钮上的小字

  • 分组标题后面如果显示 <kbd>已勾选 3/5</kbd>，说明这组 5 张表里已经有 3 张在勾选状态
  • 「一键合并」是追加式的：已经勾上的不会取消，只把没勾的补上

和「仅选中表头一致的表」有什么区别？

一键合并（概览）仅选中表头一致的表（汇总提取）
入口概览 · 表头结构分组汇总提取 · ① 选数据表工具栏
分组依据程序自动分好（只看「完全一致」）你自己挑基准，可含「缺列子集」
效果勾选 + 自动填输出字段 + 跳页只调整勾选，字段要自己选
适合表头一模一样、想快点合并表头略有差异、想精细控制

两者不冲突：可以先用「仅选中表头一致的表」框定范围，再回概览用「一键合并」快速开工。

合并前先预览（一键合并旁边的「预览」）

概览的「表头结构分组」里，每一组都有一对按钮：预览 和 一键合并。

点「预览」会真的把这一组跑一遍合并，然后弹窗告诉你：

看什么说明
一共多少行 / 多少列例如「3 张表 → 合并后 705 行 / 10 列」
参与合并的数据表每张表的实验室、工作表名，以及各自并进来多少行
合并后的列名会输出哪些字段（含自动加上的「来源实验室 / 来源文件 / 来源工作表」）
前 30 行数据真实跑出来的结果，能直接看出数据对不对、有没有空值、来源列对不对

看完觉得没问题，点弹窗右下角的「就这样合并」，就等同于点了这一组的「一键合并」 （把这组表全部勾选、输出字段自动填好、跳到「汇总提取」）；不想合并直接关闭即可。

两点说明：

  • 预览不会占用「汇总结果」，也不写任何文件 —— 它只是算一遍给你看。

真正的结果仍然要你在「汇总提取」里点「生成汇总表」才会产生。

  • 如果某张表没能并进来（比如表头识别不对、源文件不见了），预览弹窗顶部会用橙色提示

是哪张表、什么原因，比合并完才发现少了几行更容易定位。

字段不一致的表怎么一起汇总？

展开最下面的「高级：字段映射」。 程序已经帮你自动对齐了（列名一样或高度相似的会自动配上），你可以手动改每一列对应的输出字段。 例：A 表叫「需求描述」，B 表叫「问题描述」，C 表叫「内容」——把这三个都映射到输出字段「需求描述」，就能合并了。

每张表一块，点表头左边的 ▾ 箭头就能折叠 / 展开这一块； 上面还有「全部折叠」「全部展开」，表多的时候先全折叠、再展开要调的那一张。 表头右侧会显示「N 列 · 手动调过 M 列」，一眼能看出哪些表你动过。

字段映射会自动记住。 你手动调过的对应关系会存到本机配置里，

下次打开程序、或者以后再导入同样格式的表，会自动套用，不用重新调一遍。

页面右侧会显示「✓ 映射已记住，下次自动套用」。

想重来就点「清除记住的映射」。

想核对到底记住了哪些？ 点「查看映射记录」，会弹出清单： 按数据表分组，列出每条「源列 → 输出字段」（映射到"不要这一列"的会标红）。 这张清单可以直接拿来交接或排查"为什么这个字段没进结果"。

生成 → 导出

点「生成汇总表」，下面会出现结果表格。默认每页 500 行， 右下角可以切换 100 / 200 / 500 / 1000 / 2000 / 5000 行，想看多少数据直接调大即可， 用「上一页 / 下一页」翻页。导出始终是全量，不受预览行数影响。

然后点「导出 Excel」或「导出 CSV」：

  1. 浏览器会直接开始下载这一份（在浏览器默认的下载位置，比如「下载」文件夹），这是最主要的方式；
  2. 同时程序在 导出结果\ 文件夹里也存了一份备份；
  3. 导出成功后会出现一个绿色的「导出成功」卡片，上面写着文件名、大小和完整路径，

点「打开所在文件夹」就能跳到备份目录，点「再下载一次」可以重新下载。

之前版本导出后只会写进 导出结果\ 文件夹、靠一个弹窗问你要不要打开，

很容易让人觉得"没导出成功"。现在改成浏览器直接下载，就不用再去翻目录了。

清除结果

汇总结果卡片上方有两个入口可以清掉当前这份结果：

位置按钮
「生成汇总表」按钮右边清除结果
结果卡片右上角（工具栏）清除结果

点一下会先问你确认，确认后程序会：

  • 收起源卡片（结果预览、分页、来源明细一起隐藏）
  • 清空界面上的汇总结果（S.lastResult 复位）

不会影响这些东西：

  • ✅ 你导入的数据表（一张都不删）
  • ✅ 你在 ①②④ 步做的勾选和选项（原样保留，随时能重新生成）
  • ✅ 已经导出到文件的 Excel / CSV（文件还在「导出结果」文件夹里）
  • ✅ 记住的字段映射

一句话：清除结果 = 只收起桌面上这张成品表，材料和工具都还在原来位置。

找不到刚才导出的文件？

到「设置」页最下面的「最近导出的文件」，最近 15 份导出都在那里，点「下载」即可重新下载。

结果会过期吗？

不会。每次生成的结果都会存在程序目录的 library\results\ 里， 即使关掉程序重新打开，之前生成的结果也还能继续导出（下次启动时命令行窗口会提示「已载入 N 份历史汇总结果」）。

结果分析（数据概览 + 数据透视）

汇总出一张表之后，不用下载、不用再开 Excel，直接就能看这张表长什么样、或者按字段做个交叉统计。

这两个功能都在结果卡片下面的「结果分析」卡片里（生成结果后才出现，点「清除结果」会跟着一起收起）。卡片里有两个页签：

页签干什么
数据概览每一列的情况：有没有缺失、是数字还是文本、都分布成什么样、极值是多少
数据透视自己选行、列、统计方式，做一张交叉表（相当于 Excel 的数据透视表）

数据概览

点开就已经算好了，不用点任何按钮。最上面四个数字：

指标意思
总行数这份结果一共多少行
列数一共多少列
有缺失的列有多少列存在空格子（大于 0 会变成橙色）
可统计的数值列有多少列能直接做求和 / 均值

下面把每一列摊开一行，每行是：

列上显示含义
类型标签数值 / 日期 / 文本 / 长文本 / 空列（带颜色，扫一眼就知道哪列能算）
非空 / 空值这一列有多少格有值、多少格是空的（空值还带占比）
去重这一列有多少个不同的取值
内容摘要按类型给不一样的东西，见下

「内容摘要」按类型给不一样的东西：

类型摘要给什么
数值合计 · 均值 · 最小 · 最大 · 中位
日期最早 · 最晚
文本出现最多的前 5 个取值 + 各自占比，后面附「等 N 种取值」
长文本只给规模（平均多少字、多少种不同写法）—— 这种列列举前 5 名没意义
空列直接写「整列没有值」

怎么算「数值列」？ 这一列的非空值里，九成以上能转成数字才算。留一成余量是为了容忍个别写着"暂无"的格子；但不能容忍半列文字被当成数字加总。

⚠ 疑似编号：如果一列全是整数、位数又多（6 位以上）、取值还不少，会提示「疑似编号，求和/平均通常没有意义」—— 比如工号、批次号。只是提醒，不拦着你真去算。

带单位或百分号的（4.62分、12.5%）不当数值处理，免得把「评分等级」「满意度百分比」这类字段加成一锅粥。有千分位的（1,234）能正常认出来。

数据透视

四步，思路跟 Excel 的数据透视表一样：

① 行维度 —— 左边下拉选一个字段，点「＋ 加为行维度」，它就变成一个带序号的小标签。

  • 可以加多个（最多 3 个），标签上的序号就是层级顺序，点标签上的 ✕ 移除
  • 一个都不加也行 —— 那就只按列维度横向展开

② 列维度（可选）—— 想让哪个字段的取值横着铺开就选它。不选就是普通的一列数字（每行一个值）。

③ 字段 + 聚合方式

聚合方式意思要不要选「字段」
计数（有几行）每个分组里有几行不用
去重计数（几个不同值）每个分组里有几个不同取值要
求和把该字段的值加起来要
平均该字段的平均值（保留 2 位小数）要
最大值该字段的最大值要
最小值该字段的最小值要

除了「计数」，其它都必须指定字段 —— 否则程序不知道你要统计的是哪一列的值。没选就点「生成透视表」，会直接提示你先选一个。

下拉框下面有一行灰字会实时告诉你当前这个聚合方式要不要选字段。

④ 两个勾

勾默认意思
显示合计行列勾上关掉就只剩明细分组，没有「总计」行和「合计」列
丢掉分组键全空的行不勾勾上 = 行维度全都是空的那些行不参与统计

然后点「生成透视表」。

关于透视结果，几件要知道的事：

  • 空值单独成一组，标签是「（空）」，永远排在最后，不会被当成 0。
  • 分组值按自然序排：1月 < 2月 < 10月，不是字典序的 1月 < 10月 < 2月。
  • 空值不参与数字计算：算平均、求和时，空着的格子直接跳过，不是当 0。表格下方会写明「N 个单元格不是数字，未计入」。
  • 行数多也不会卡：结果最多能有 30 万行，但透视是在后台算完再把表格送到界面的，所以 1000 行和 30 万行用起来一样快。
  • 分组太细会被拦下来：如果行维度选得像「需求描述」这种几乎每行都不一样的字段，分组会超过 2 万组，程序会直接提示你换个字段，而不是硬算到浏览器卡死。
  • 界面最多显示 2000 行（分组更多时表格下方会提示「分组共 N 组，界面只显示前 2000 组（导出仍是全量）」）—— 但导出始终是全量。

「合计 / 总计」是怎么算的（这块最容易看错）：

聚合方式合计怎么来
求和真求和（各格相加）
平均总数 ÷ 总条数，不是「把各格的平均值再平均一遍」
去重计数整个分组去重，不是各格去重数相加
最大 / 最小该行（列）内的极值
计数该行（列）的行数加总

导出透视表

透视表生成后，右上角有「导出 Excel」和「导出 CSV」：

  1. 点一下浏览器直接下载（跟导出汇总结果一个套路）；
  2. 同时也在 导出结果\ 文件夹里留一份备份；
  3. 文件名形如 数据透视_行维度名_20260921_173000.xlsx；
  4. 导出完成会提示「透视结果已导出：文件名（全量 N 行）」。

导出的一定是全部行，不会跟着界面只导 2000 行。

分析报告（v2.1.0 新增）

数据透视给的是表格，分析报告给的是一份能直接发出去的 HTML。同样挂在这张结果卡片下面，在「结果分析」再往下一点。它是选好模板、一键生成——不用每次重新想怎么分析，出来的版式每份都一样。

生成报告需要这份数据里有三列：检测完成时间、模块（仪器/通道）、项目名称。程序会自己按关键词去找，列名不完全一样也能认出来（比如叫「完成时间」「出结果时间」都行）；界面上会写清它认到了哪一列。

多天数据怎么处理

如果你的数据横跨好几天（比如一份表里既有 09/19 又有 09/20），程序会自动识别并做三件事：

环节怎么处理为什么
时段桶按天隔离：09/19 的 9 点和 09/20 的 9 点是两个独立格子，不会相加否则两天的量叠成一个桶，峰值、集中度全部失真
队列重建 + 饱和窗（模板②）每天各算一遍，再取速度最高的那天作为能力证据队列是「当天从零起算」的积压量；跨天累加会把前一天的积压带进第二天，速度就算错了
报告章节多一节「逐日对比」：每天的完成量、峰值时段、当天饱和窗、当天实际速度并排列出一眼看出哪天最忙、哪天没跑满

单天数据的行为和以前完全一样，报告版式不变。多天时结论会写成「N 天合计 / 平均每天」，并给出单日区间。

时间列如果是「只有日期、没有时刻」（如只写 2026/09/19）：这些行只贡献「当天完成量」，不进小时桶（程序不会替你编造一个「00:00–01:00」的凌晨时段）。报告里会标注有多少行属于这种情况。

跨天的时段不会连成一片：饱和窗只在同一天内部找。比如两天各有一段 4 小时的高峰，报告会得到「4 小时」的饱和窗，而不是错误的「8 小时」。

怎么生成

  1. 点一下模板卡片（选中会变蓝）；
  2. 下面出现参数框，按需填（不填就用默认值）；
  3. （可选）填个报告文件名，留空就用「模板默认名 + 日期」；
  4. 点「生成报告」。

生成完会出现一条绿色结果条，写着文件名、大小、用时和几个关键指标，下面三个按钮：在浏览器里打开 / 打开所在文件夹 / 复制文件路径。

报告是独立文件，存在程序目录的 分析报告\ 里，跟程序窗口没关系 —— 关掉程序、拷给别人、打印成 PDF 都行。同名不会覆盖，会自动加 (1)、(2)。图表需要联网加载；没网也能看，只是图变成一句提示，表格和结论照常。

参数怎么填

设备模块负载与堵塞点 —— 这个模板不用填参数。

免疫线实际测试速度·证据链 —— 四个参数：

参数默认怎么理解
单模块标称速度270一台模块一小时标称能做多少个测试。i6000 系列一般就是 270。填小了会把饱和度算高，没把握别动。
真机模块数留空把多台设备的表合并时，这个必须填。见下面的橙色说明。
测速窗口autoauto = 程序自己找最忙的那段当窗口；也可以手填 14,20 表示只用 14:00–20:00 这段算。
对照组模块空填了之后这些模块在报告里灰显、不参与速度结论（比如 2联机跟 3联机不能放一起比）。多个用逗号分隔，如 M2,M3。

⚠ 两台设备的表合并时，一定要填「真机模块数」

两台 3联机（比如 0919-2 和 0919-3）都有 M1 / M2 / M3，一合并名字就撞上了。程序如果只看到 3 个名字，就会以为全厂只有 3 个模块，把产能算少一半，算出来的速度虚高一倍。

程序会自己按「来源文件 × 模块名」的组合去估真机模块数（两台 3联机 = 6），并在报告里写明「已按 N 个真机模块计产能」。但如果来源列缺失或本身就不准，你得手工填。

填小了不采信：填的数比程序估出来的还小，程序会忽略你、仍按自动值算，防止速度虚高。

九、常见问题

Q：点「生成汇总表」，提示「找不到源文件」？ 说明 library\sources\ 里的原始文件没了。 什么时候会发生：拷程序时只拷了 library\index.json、没拷 library\sources；手工清理过 sources 文件夹；换了电脑。 怎么修：到「数据源管理」页把这些旧记录删掉，重新导入一遍原始 Excel（导入后字段会重新自动识别）。

左侧列表里的表名和字段是索引（index.json），即使原始文件丢了也照样显示，

所以会出现"看起来有 5 张表、34 个字段，一点生成却报错"的情况。

Q：结果是 0 行？ 结果区会列三条排查提示：① 筛选条件把数据全过滤掉了；② 勾选的字段和这些表对不上（展开「字段映射」看看每列有没有配上）；③ 选错了工作表。

Q：点了「导出 Excel」没反应 / 找不到文件？

  • 先看有没有绿色的「导出成功」卡片，或者红色的错误卡片 —— 现在失败一定会明确告诉你原因。
  • 浏览器会自动下载一份，去浏览器的下载位置找（一般是「下载」文件夹）。
  • 备份在程序目录的 导出结果\ 里；到「设置」页最下面的「最近导出的文件」也能看到并重新下载。
  • 如果提示「请先点上面的生成汇总表」：说明当前没有可导出的结果，先在第 ① / ② 步选好表与字段、生成结果，再导出。

Q：字段名怎么变成 列6、列7、列8 了？ 说明表头那行被认错了（认成了第一条数据行）。到「数据源管理」→ 该工作表「详情」， 把「表头行」手动改成正确行号（通常就是 1），点「重新识别」即可。

新版识别规则已经修好了「表头里有一整列还没填 → 认错表头」这类问题；

升级后老数据会在启动时自动重算，命令行窗口会提示「已按新版识别规则刷新 N 个数据表的识别结果」。

另外：如果某个工作表本身就没有表头行（比如第一行直接是数据），

出现 列1、列2 是正常的 —— 那是源表里真的没写列名。

Q：点「生成汇总表」按钮完全没反应？ 这是程序早期版本的一个 bug：「生成汇总表」按钮忘了接上点击事件（函数写好了但没接线）， 现在已经修好。请把程序重启一次（关掉黑色窗口，重新双击 start.bat）， 然后刷新一下浏览器页面（按 F5），让新版界面生效。

新版还加了开机自检：如果再有按钮没接上，页面会直接弹红框告诉你，不会再"静默无反应"。

Q：导入一个很大的工作簿特别慢 / 卡住？ Excel 里给整列拖过边框或格式之后，文件会"声称"这个工作表有 104 万行， 实际上里面绝大多数是空行。老版本会老老实实读完这 100 万行，一个 4MB 的文件要 25 秒。 新版会先扫一遍只读真正有数据的行 —— 同样这个文件降到 6 秒以内。

如果你手上还有特别大的表，导入后留意一下「数据源管理」里显示的行数：

如果行数明显比实际大很多（比如显示 100 多万），说明是老版本导入的记录，

重启程序会自动重算。

Q：备份要拷什么？ 拷 library\ 整个文件夹（含 index.json 和 sources\）。只拷 index.json 会丢源文件，下次汇总就会报「找不到源文件」。

Q：程序放哪儿好？ 放哪都行，但不要放在钉钉网盘同步目录里（同步会锁文件）。建议放 D:\智慧实验室数据汇总助手\ 这类本地目录。

Q：升级了程序版本，老数据要重新导入吗？ 不用。新版启动时会自动按新的识别规则刷新所有表的结构信息，命令行窗口会打印「已按新版识别规则刷新 N 个数据表的结构信息」。

Q：.xls（老格式）导不进来？ 程序只支持 .xlsx / .xlsm / .csv。用 Excel 打开 .xls 另存为 .xlsx 即可。

Q：表格特别大（几万行）会不会卡？ 读取和汇总都是流式的，几万行没问题。汇总结果默认只预览前 300 行，导出的是全量。

Q：能让两个人同时用吗？ 这是本机程序，只监听 127.0.0.1，别人访问不到。想共享就把程序目录放在共享盘上各自运行，或者在各自的电脑上装一份。

Q：端口被占用？ 程序会自动往后找 8765~8804 里没被占用的端口，看命令行窗口显示的地址为准。

Q：黑色窗口关了 / 网页提示「连不上本地程序了」？ 程序是跟着那个黑色窗口跑的，关掉窗口程序就停了。重新双击 start.bat，然后刷新网页即可。
