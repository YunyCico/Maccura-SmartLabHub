快速开始

  1. 导入表格 —— 进「数据源管理」，把各实验室的 Excel 拖进来（支持一次多选、也支持整个文件夹）
  2. 确认字段 —— 程序会自动猜表头行，多行表头/合并单元格会拼成一个字段名，不对可手动改
  3. 选字段汇总 —— 进「汇总提取」，勾选要的数据表 → 勾选想要的字段 → 点生成
  4. 导出 —— 结果直接导出成 Excel，文件在程序目录的「导出结果」文件夹里

汇总提取

① 选择要汇总的数据表

「仅选中表头一致的表」只比对表头列名，与单元格内容无关。点开后可自己挑一张表作基准，并选择全库或仅在已勾选的表里对齐 —— 会先列出「完全一致 / 缺列子集 / 表头不符」三档让你确认。
勾选后点「查看已勾选」可以一次性看到所有已勾选的工作表，在弹窗里直接取消勾选，不用在长列表里一个个找。
